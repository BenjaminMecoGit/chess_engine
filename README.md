This is a custom chess program in which you can play with (locally) against a friend or against the computer with the color of your choice. 
You can also explore various chess positions and see how the bot evaluates them (work in progress).

The bot is continuously optimized bit by bit, currently it seems to be around 900 - 1000 ELO in strength. 

The entire project is written in the RUST programming language. 

To run the binary, which is called chess_engine and can be found in target/release, download it and the assets folder and place them in the same directory.
